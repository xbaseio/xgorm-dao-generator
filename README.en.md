# xgorm-dao-generator

Generate GORM DAOs from Go struct models. Each model produces two layers:

- `internal`: columns, query helpers, and CRUD implementation.
- Public DAO: database instance, table name, and extension point for business code.

## Installation

```bash
go install github.com/xbaseio/xgorm-dao-generator@latest
```

## Basic usage

```bash
xgorm-dao-generator \
  -model-dir=. \
  -model-names=User,Wallet \
  -dao-dir=../dao/ \
  -sub-pkg-enable=true \
  -mysql-pkg-path=/internal/component/mysql/mysql-default
```

| Flag | Default | Description |
| --- | --- | --- |
| `-model-dir` | empty | Model directory; required |
| `-model-names` | empty | Comma-separated model names; required. Use `Model:table_name` to override a table name |
| `-dao-dir` | empty | DAO output directory; required |
| `-model-pkg-path` | auto-detected | Import path of the model package |
| `-model-pkg-alias` | auto-detected | Import alias for the model package, for example `modelpkg` |
| `-dao-pkg-path` | auto-detected | Import path of the DAO package |
| `-sub-pkg-enable` | `false` | Put each model in its own DAO package |
| `-sub-pkg-style` | `kebab` | Sub-package directory style: `kebab`, `underscore`, `lower`, `camel`, or `pascal` |
| `-file-style` | `underscore` | Generated file style: `kebab`, `underscore`, `lower`, `camel`, or `pascal` |
| `-mysql-pkg-path` | empty | Database component path for the public DAO |
| `-instance-func` | `Instance` | Database instance function: `Instance`, `InstanceWrite`, or `InstanceRead` |
| `-include-anonymous` | `false` | Include fields from anonymous embedded structs |

`-model-dir` and `-dao-dir` accept relative paths resolved from the command working directory. Package path flags only affect generated imports; they do not create or migrate a database.

## Anonymous embedded fields

Anonymous embedded fields are skipped by default:

```go
type User struct {
    ID int
    ModelTime
}
```

Only `ID` is generated by default. Enable expansion explicitly when inherited fields
must be present in DAO Columns:

```bash
xgorm-dao-generator -model-dir=. -model-names=User -dao-dir=../dao/ -include-anonymous=true
```

For admin models, keeping the default disabled is recommended because embedded fields
are commonly shared ORM behavior rather than DAO columns.

## go:generate

```go
//go:generate xgorm-dao-generator -model-dir=. -model-names=User -dao-dir=../dao/ -sub-pkg-enable=true
```

Run it with:

```bash
go generate ./...
```

Do not edit generated `internal` files manually. Put business extensions in the public DAO layer.
